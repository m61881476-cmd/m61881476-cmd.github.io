# سيرفر إشعارات دفتر

ده سيرفر صغير ببلاش على **Cloudflare Workers** بيحفظ اشتراكات الإشعارات ويبعت منها. التطبيق نفسه بيفضل زي ما هو على GitHub Pages؛ السيرفر ده شغلته الإشعارات بس، ومش بيوصله أي بيانات محاسبية.

## بيشتغل على إيه

| الجهاز | الشرط |
|---|---|
| أندرويد | Chrome أو Edge أو Samsung Internet، من المتصفح أو التطبيق المتثبّت |
| آيفون / آيباد | **iOS 16.4 أو أحدث**، ولازم دفتر يكون متثبّت على الشاشة الرئيسية (من Safari ← مشاركة ← إضافة إلى الشاشة الرئيسية). من تبويب Safari العادي مش هينفع، ودي قاعدة أبل |
| كمبيوتر | Chrome و Edge و Firefox و Safari على الماك |

الإشعار بيوصل حتى والتطبيق مقفول.

## الإعداد (مرة واحدة، حوالي 10 دقايق)

محتاج Node.js على جهازك وحساب مجاني على cloudflare.com.

```bash
cd daftar/push
npm install

# 1) اعمل مفاتيح VAPID (مرة واحدة بس، واحتفظ بيهم)
npm run keys

# 2) سجّل دخول Cloudflare واعمل مخزن للاشتراكات
npx wrangler login
npx wrangler kv namespace create SUBS
```

افتح `wrangler.toml` وحط فيه:
- الـ `id` اللي طلع من الأمر الأخير.
- `VAPID_PUBLIC_KEY` = المفتاح العام.
- `VAPID_SUBJECT` = رابط موقع دفتر (مثلاً `https://NAME.github.io/daftar/`) أو `mailto:` إيميلك.
- `ALLOWED_ORIGINS` = رابط موقع دفتر من غير مسار (مثلاً `https://NAME.github.io`) عشان محدش غيره يسجّل اشتراكات. أو سيبه `*`.

بعدين حط الأسرار وارفع:

```bash
npx wrangler secret put VAPID_PRIVATE_KEY   # الصق المفتاح السري
npx wrangler secret put ADMIN_TOKEN         # اختار كلمة سر طويلة، دي اللي هتبعت بيها
npm run deploy
```

هياخد رابط زي `https://daftar-push.NAME.workers.dev`.

**3) اربط التطبيق بالسيرفر:** افتح `push-config.js` في فولدر دفتر الرئيسي وحط الرابط والمفتاح العام:

```js
self.DAFTAR_PUSH = {
  server: 'https://daftar-push.NAME.workers.dev',
  vapidPublicKey: 'B…المفتاح العام…',
};
```

وغيّر رقم `VERSION` في أول `sw.js` (مثلاً `daftar-shell-v1.3.1`) وارفع على GitHub.

## اللي هيحصل عند المستخدمين

1. اللي متثبّت عندهم دفتر هيظهرلهم «يوجد تحديث جديد» ← «تحديث الآن» (أو التحديث بيتطبق لوحده تاني مرة يفتحوا).
2. بعد التحديث، دفتر هيسألهم **مرة واحدة**: «تحب توصلك إشعارات من دفتر؟». لو وافقوا، الجهاز بيظهر طلب الإذن الرسمي.
3. أي حد يقدر يشغّلها أو يقفلها بعدين من **الإعدادات ← التذكيرات ← إشعارات على الموبايل**، وفيه زرار «جرّب إشعار دلوقتي».
4. على الآيفون من غير تثبيت، الإعدادات بتقوله يثبّت التطبيق الأول وبتوريه الخطوات.

مهم: **مفيش طريقة تبعت إشعار لحد ما وافقش**، لا على أندرويد ولا آيفون. فكل اللي متثبّت عندهم دفتر دلوقتي لازم يفتحوه مرة بعد التحديث ويوافقوا.

## إرسال إشعار

افتح `push/admin.html` (من موقعك: `https://NAME.github.io/daftar/push/admin.html`، أو من الملف على جهازك)، واكتب رابط السيرفر وكلمة سر المسؤول، والعنوان والنص، واختار الصفحة اللي تتفتح لما يدوس (المحادثة، التحليلات…) ومين يوصله (الكل / أندرويد / آيفون)، ودوس «ابعت». فيه كمان زرار يوريك عدد المشتركين.

أو من الترمنال:

```bash
curl -X POST https://daftar-push.NAME.workers.dev/send \
  -H "Authorization: Bearer ADMIN_TOKEN" -H "Content-Type: application/json" \
  -d '{"title":"دفتر 1.3 نزل","body":"افتح التطبيق وجرّب الجديد","url":"./#chat"}'
```

الرد فيه `cursor`؛ لو مش `null` ابعت نفس الطلب تاني ومعاه `"cursor":"…"` لحد ما يرجع `done: true` (السيرفر بيبعت 40 جهاز في كل مرة عشان حدود الخطة المجانية). صفحة الأدمن بتعمل ده لوحدها.

## الحدود المجانية

- Workers: 100 ألف طلب في اليوم.
- KV: ألف اشتراك جديد/تعديل في اليوم و100 ألف قراءة. يعني الإرسال لحد ~50 ألف جهاز في اليوم من غير فلوس.
- الاشتراكات اللي اتلغت (المستخدم مسح التطبيق) بتتشال لوحدها أول ما الإرسال ليها يفشل.
