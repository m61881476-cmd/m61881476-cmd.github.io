# 16 — Changelog

This file records the versions of the package and the open items for later editions.

## Versioning scheme

The package and each document use three numbers: `MAJOR.MINOR.PATCH`.

- **MAJOR** changes when earlier guidance becomes invalid, for example after a new model release or a rewritten prompt.
- **MINOR** changes when material is added: new tests, new modules, new sections.
- **PATCH** changes for corrections that do not alter the guidance.

The benchmark suite has its own version in the `suite_version` field of each test. Scores from different suite versions must not be compared.

### Sources

Eight public Anthropic pages, retrieved 2026-11-14. The list is in `00_README.md`, section 2. The SHA-256 hash of the retrieved system prompt page is recorded in `02_OFFICIAL_SYSTEM_PROMPT.md`.

### Checks performed for this edition

- The benchmark file was generated by a script and then parsed: 25 valid JSON lines, unique identifiers, 5 tests per category, and all required fields present.
- Answer keys that can be computed were checked by the same script: the reference implementations for CODE-02, CODE-04, PLAN-03, VERIFY-02, and VERIFY-03 were executed against the cases listed in their criteria; the numeric keys for REASON-01, REASON-04, and VERIFY-01 were recomputed; the floating-point result in VERIFY-04 was evaluated.
- The verbatim system prompt was inserted by a script from the retrieved page, not retyped.
- The file list was compared with the required list, and references between files were checked.

### Known gaps

1. **No testing on target models.** The master prompt and the suite were not run against any model other than by the author's reading. All guidance on other model families is unverified.
2. **No reference transcripts.** The suite's expected behaviors are a specification. Recorded Fable 5.2 outputs for each test would be stronger.
3. **Sources not read.** The system card, the launch announcement, the dedicated pages on effort, adaptive thinking, preserved thinking, and refusals, and Anthropic's terms and usage policies.
4. **Benchmark table not transcribed.** The figures on the product page could not be reliably matched to their columns from the plain-text extraction.
5. **Single-session observation.** One agentic session at `medium` effort under one harness.
6. **Short tests only.** The suite has no long-horizon, large-context, or multi-agent tests.

## Maintenance rules

1. When Anthropic updates the published system prompt, add the new entry to `02_OFFICIAL_SYSTEM_PROMPT.md` with its date and hash. Keep the old entry and mark it superseded.
2. When a fact in `01_MODEL_PROFILE.md` changes, change it there only. Other files link to it.
3. When a test changes, raise `suite_version`, and re-verify its answer key by a second route.
4. Record every change here with the date, the files, and the reason.
5. Do not remove an evidence label. If a claim is later verified, change the label and name the source.
