# ستوديو المونتاج

الاستوديو في `studio/` (صفحة ثابتة، بتتنشر مع الموقع على `/studio/?p=<id>`).
أنت بتكتب **خطة المونتاج** بس في `studio/projects/<id>/project.json`؛ حركة الوكلاء (المؤشرات، السجل، بناء التايملاين) بتتولّد لوحدها من الخطة، والمعاينة والتصدير بيستخدموا نفس كود الرسم.

## الخطوات

1. **الخامات**: حط لقطات المستخدم في `studio/projects/<id>/` بعد تحويلها لـ H.264 خفيف (المتصفحات مابتشغّلش HEVC دايماً):
   `ffmpeg -i in.mp4 -vf "scale=-2:1280" -c:v libx264 -crf 24 -preset slow -c:a aac -b:a 128k -movflags +faststart a.mp4`
   الصور (jpg/png/webp) بتشتغل كمصدر عادي. خلي الملف الواحد تحت ~20MB.
2. **افهم اللقطات قبل ما تقص**: طلّع فريمات (`ffmpeg -vf fps=1,scale=360:-1,tile=6x5`) وشوفها، ولو فيه كلام استخرج الصوت واكتب الترجمة بتوقيتاتها الحقيقية (silencedetect بيساعد في أماكن القص). ماتخمّنش كلام ماسمعتوش؛ لو مفيش وسيلة تفريغ اسأل المستخدم عن النص.
3. **اكتب `project.json`** (الصيغة تحت) وضيف المشروع في `studio/projects/index.json`.
4. **الفيديو النهائي**: `node studio/tools/render.cjs <id>` ← `studio/projects/<id>/final.mp4`.
5. **فيديو الكواليس** (الوكلاء شغّالين ثم النتيجة، زي الريلز): `node studio/tools/record.cjs <id> --layout p` (أو `l` للعرض) ← `studio/out/<id>-making-of.mp4` (مش بيتعمله commit).
6. **اتفرّج قبل ما تسلّم**: طلّع فريمات من الناتجين وراجعها بعينك (الترجمة مقروءة ومش مغطية وش، القصّات في مكانها).
7. ابعت الملفين للمستخدم بـ SendUserFile، واعمل commit للمشروع على الفرع المطلوب.

## صيغة project.json

```json
{
  "title": "اسم الفيديو",
  "format": { "w": 1080, "h": 1920, "fps": 30 },
  "final": "final.mp4",
  "sources": { "a": { "file": "a.mp4", "label": "لقطة أ", "audio": true } },
  "music": { "file": "music.m4a", "label": "اسم التراك", "volume": 0.2, "start": 0 },
  "look": { "exposure": 1.05, "contrast": 1.1, "saturation": 1.2, "temp": 0.1 },
  "captionStyle": { "style": "pop", "font": "Cairo", "color": "#ffd60a", "position": 0.7, "size": 1 },
  "segments": [
    { "src": "a", "in": 1.2, "out": 4.0, "zoom": [1, 1.15], "focus": [0.5, 0.35], "transition": "flash", "mute": false, "volume": 1 }
  ],
  "captions": [ { "start": 0.2, "end": 2.4, "text": "تلات لأربع كلمات" } ],
  "pieces": [
    { "type": "bar", "start": 0 },
    { "type": "title", "start": 0.2, "end": 2.5, "text": "العنوان", "sub": "سطر صغير", "color": "#a8f05a", "y": 0.2 },
    { "type": "lower", "start": 5, "end": 8, "text": "الاسم", "sub": "الوصف", "y": 0.5 },
    { "type": "sticker", "start": 9, "end": 10.5, "text": "واو!", "x": 0.5, "y": 0.36, "rot": -8, "size": 0.16 },
    { "type": "cta", "start": 14, "end": 16, "text": "تابعني", "y": 0.9 }
  ],
  "show": { "build": 20 }
}
```

- `segments` بالترتيب هي التايملاين؛ `in/out` بالثواني جوه المصدر (للصور استخدم `dur`). مدة الفيديو = مجموعها.
- توقيتات `captions` و`pieces` على زمن **المونتاج** مش زمن المصدر. الترجمة بتتميّز كلمة بكلمة بالتساوي على مدتها، فخلي كل سطر قصير.
- `zoom` [بداية، نهاية]، `focus` مركز الزووم (0..1)، `transition`: `flash` | `punch` | `none`.
- `look`: الحياد = exposure 1, contrast 1, saturation 1, temp 0 (temp من -1 أزرق لـ +1 دافي).
- `captionStyle.style`: `pop` | `box` | `plain`. `position` نسبة من ارتفاع الفيديو.
- `sources.*.audio: false` لو اللقطة من غير صوت أو مش عايزين صوتها. صوت اللقطات بيتقص مع الفيديو والموسيقى بتتحط تحته.
- `show.build` مدة عرض الوكلاء بالثواني (اختياري).

## ملاحظات

- الكروميوم في البيئة مش بيفك H.264، فالأدوات بتعمل نسخ WebM مؤقتة لوحدها؛ الملفات اللي في المشروع تفضل MP4 علشان الموبايل.
- الخط Cairo متضمّن في `studio/fonts`. مفيش خط إيموجي ملوّن مضمون في التصدير، فتجنّب الإيموجي جوه النصوص المرسومة.
- لو المستخدم ماعندوش موسيقى، ماتستخدمش موسيقى محمية بحقوق؛ اسأله أو ولّد إيقاع بسيط.
- أي ميزة جديدة في الرسم تتضاف في `studio/studio.js` (دالة `drawResult` وأخواتها) فتظهر في المعاينة والتصدير مع بعض.
